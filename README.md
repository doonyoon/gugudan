# 고양이 성채전

설치 없이 실행되는 오리지널 횡스크롤 고양이 디펜스 웹 게임입니다.

## 실행

`index.html`을 브라우저에서 열면 바로 실행됩니다. 로컬 서버가 필요하다면 다음 명령을 사용하세요.

```powershell
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`으로 접속합니다.

## 구성

- `index.html`: 게임 화면과 접근성 구조
- `style.css`: PC·모바일·가로 화면 반응형 디자인
- `game.js`: Canvas 전투, 유닛, 적, 자원, 사운드 시스템
- `.github/workflows/deploy-pages.yml`: GitHub Pages 자동 배포

외부 패키지나 빌드 과정은 필요하지 않습니다.

## 게임 기능

- 점점 강해지는 20개 스테이지
- 아이디·비밀번호 회원가입·로그인·비밀번호 재설정, 브라우저별 계정 저장 및 로그아웃
- 스테이지 난이도에 비례하는 승리 골드
- 스테이지마다 시작 물고기·생산량·보유 한도·아군 기지 체력이 증가하는 완만한 난이도 보정
- 후반의 최강 적은 일반 웨이브가 아닌 매 10번째 보스 웨이브에 등장
- 기본 캐릭터 4종과 다양한 등급의 뽑기 캐릭터 18종
- 300골드 캐릭터 뽑기와 중복 캐릭터 레벨 강화
- 등급별 뽑기 확률: 노멀 50%, EX 25%, 레어 9%, 슈퍼 레어 10.7%, 울트라 슈퍼 레어 5%, 레전드 레어 0.3%
- 골드, 클리어 기록, 캐릭터 보유 현황 자동 저장
- 전투 중 확인 후 보상 없이 인트로로 돌아가는 전투 포기 기능
- 물고기를 사용하는 캐릭터별 전투 훈련(최대 5단계)
- 이름과 역할에 맞는 캐릭터별 무기·모자·장비 디자인
- 스테이지마다 달라지는 적 9종과 시간이 지날수록 강해지는 적 웨이브
- 초원·붉은 협곡·달빛 늪지·도시·빙하·화산·폭풍·우주 등 스테이지별 전용 배경
- 광륜·화면 발광·색종이·등급별 사운드가 적용된 뽑기 연출
- 선물 코드 `9027` 최초 입력 시 10,000골드 지급
- 보유 캐릭터 중 4종을 선택해 저장하는 출전 슬롯 편성
- 소환 카드와 뽑기 도감에 캐릭터 등급·레벨·물고기 비용 표시
- 목표가 죽으면 다음 적을 추적하고 적이 없으면 기지를 타격하는 원거리 유도탄
- 초반 자원·기지 체력 상향과 적 체력·출현 빈도·시간 강화 하향으로 조정된 난이도

## 캐릭터 스프라이트

`assets/characters`의 PNG 스프라이트를 사용합니다. 한 이미지는 가로 4칸, 세로 2줄 구조입니다.

- 상단 4프레임: 이동
- 하단 4프레임: 공격
- 현재 적용: 날쌘냥, 농부냥, 방패냥, 복서냥, 사무라이냥, 요리사냥, 별빛냥, 의무냥, 잠꾸러기냥, 해적냥

새 이미지는 `game.js`의 `CHARACTER_SPRITES`에 캐릭터 타입과 파일명을 추가하면 전투·소환 카드·편성 화면에 함께 적용됩니다.

의무냥은 부상당한 팀원 중 등급이 가장 높은 캐릭터를 먼저 치료하며, 같은 등급에서는 체력 비율이 낮은 팀원을 우선합니다.
